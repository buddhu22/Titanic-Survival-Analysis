
🚢 Titanic Survival Analysis Dashboard

A Machine Learning-powered interactive dashboard that analyzes passenger survival patterns from the famous Titanic disaster dataset.

Live Demo: https://titanic-survival-analysis18.streamlit.app/

---

Project Overview

This project explores the Titanic dataset using Data Analysis, Data Visualization, and Machine Learning techniques.

The dashboard allows users to:

- Explore passenger demographics
- Analyze survival trends
- Visualize important features
- Predict passenger survival probability using Machine Learning
- Interact with data through a modern Streamlit interface

---

 Objectives

- Perform Exploratory Data Analysis (EDA)
- Understand factors affecting survival
- Build predictive Machine Learning models
- Create an interactive web dashboard
- Deploy the project publicly using Streamlit

---

Dataset Information

The dataset contains information about Titanic passengers, including:

Feature| Description
PassengerId| Unique passenger ID
Pclass| Passenger class
Name| Passenger name
Sex| Gender
Age| Age of passenger
SibSp| Number of siblings/spouses aboard
Parch| Number of parents/children aboard
Ticket| Ticket number
Fare| Ticket fare
Cabin| Cabin number
Embarked| Port of embarkation
Survived| Survival status (Target Variable)

Dataset Source: Titanic Passenger Dataset
